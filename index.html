Google-Verbindung einrichten

  1. In der Google Cloud Console ein Projekt für Shogi Space erstellen.
  2. Die Gmail API aktivieren.
  3. Unter „Google Auth Platform“ die App konfigurieren. Bei Verwendung im Testmodus beide Gmail-Konten als Testnutzer hinzufügen.
  4. Eine OAuth-Client-ID vom Typ „Webanwendung“ erstellen. Als autorisierten JavaScript-Ursprung die Adresse ohne Pfad eintragen: https://uunimed.github.io.
  5. Die Client-ID unter „E-Mail“ einfügen und speichern. Anschließend jedes Gmail-Konto einzeln verbinden und einen Bereich auswählen.

Für GitHub Pages ist der Ursprung gewöhnlich https://uunimed.github.io, ohne /admin/. Bei einer eigenen Domain muss deren Ursprung verwendet werden.

Die Verbindung benötigt Zugriff auf das Lesen von E-Mails und das Ändern des Lesestatus. Nachrichten und Zugangstoken werden nicht in den Seiteneinstellungen gespeichert.

Google-Zugriffstoken sind zeitlich begrenzt. Nach Ablauf oder erneutem Öffnen der Seite kann „Erneut verbinden“ erforderlich sein.

Die Verbindung funktioniert über HTTPS oder einen lokalen Webserver. Eine direkt geöffnete HTML-Datei kann keine Google-Anmeldung verwenden.
